# Ingot

Ingot is a Minecraft launcher and server host built with Tauri and React.

## Icon assets

Effect and enchantment symbols use [Lucide](https://lucide.dev/), which is licensed under [ISC](https://github.com/lucide-icons/lucide/blob/main/LICENSE). Its full license notice is included in [`public/THIRD_PARTY_NOTICES.txt`](public/THIRD_PARTY_NOTICES.txt) and distributed with the app. These are representative symbols, not original Minecraft or Enchant Icons resource-pack artwork. Unknown or modded effects and enchantments use a generic symbol.
